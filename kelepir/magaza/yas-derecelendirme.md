# Yaş derecelendirme anketi — cevap anahtarı

İki mağazanın ayrı anketi var. İkisinde de hedef **en düşük derece**; oyunda
şiddet, cinsellik, küfür, kumar ve kullanıcılar arası iletişim yok.

---

## GOOGLE PLAY — IARC anketi

| Soru | Cevap |
|---|---|
| Şiddet içeriyor mu? | Hayır |
| Korku / rahatsız edici içerik? | Hayır |
| Cinsellik veya müstehcenlik? | Hayır |
| Küfür / argo? | Hayır |
| Uyuşturucu, alkol, tütün? | Hayır |
| **Kumar** — gerçek parayla? | Hayır |
| **Simüle kumar** (kumar mekaniği, sanal bahis)? | **Hayır** |
| Kullanıcılar birbiriyle iletişim kurabiliyor mu? | Hayır |
| Kullanıcı konumu paylaşılıyor mu? | Hayır |
| Kullanıcı tarafından üretilen içerik var mı? | **Evet — yalnızca kendi galeri adı, başkası görmüyor** |
| Uygulama içi satın alma var mı? | Hayır |
| Dijital ürün satın alınabiliyor mu? | Hayır |
| Reklam gösteriliyor mu? | Hayır |

**Beklenen sonuç:** Türkiye'de **3+ / Herkes**.

### "Simüle kumar" sorusuna dikkat
Oyunda **müzayede** var. IARC'ın kastettiği simüle kumar, şans oyunu
mekaniği (slot, rulet, kart, kasa açma). Müzayede bir fiyat yarışıdır,
şans oyunu değil; kutu/kasa açma (loot box) mekaniği de yok. Yine de
anketin açıklama alanına şunu yaz:

> Oyunda açık artırma (müzayede) ile araç satın alma var. Bu bir şans
> oyunu değildir: fiyat teklifi verilir, en yüksek teklif kazanır.
> Rastgele ödül kutusu, bahis veya kumar mekaniği yoktur.

### Kullanıcı içeriği sorusuna dikkat
Oyuncu galerisine isim veriyor (`lotAd`). Bu isim **cihazdan çıkmıyor**,
başka kimse görmüyor. Açıklama alanına:

> Oyuncu yalnızca kendi galerisine bir isim verebilir. Bu metin cihazda
> kalır, paylaşılmaz, başka kullanıcılara gösterilmez. Moderasyon
> gerekmez çünkü iletim yoktur.

## APPLE — güncel yaş derecelendirme anketi

Apple anketi **31 Ocak 2026**'da değişti; yeni yaş bantları **4+, 9+, 13+,
16+, 18+**. Eski derecesi olan uygulamalar yeni soruları cevaplamadan
gönderim yapamıyor. Kelepir yeni uygulama olduğu için doğrudan yeni anketi
dolduruyorsun.

| Soru grubu | Cevap |
|---|---|
| Şiddet (karikatürize / gerçekçi) | Yok |
| Korkutucu veya rahatsız edici temalar | Yok |
| Cinsel içerik veya çıplaklık | Yok |
| Küfür veya kaba mizah | Yok |
| Alkol, tütün, uyuşturucu | Yok |
| **Kumar** (gerçek para) | Hayır |
| **Simüle kumar** | Hayır |
| Yarışmalar / çekilişler | Hayır |
| Kullanıcılar arası iletişim | Hayır |
| Kullanıcı tarafından üretilen içeriğe erişim | Hayır |
| Kontrolsüz web erişimi | Hayır |
| Konum paylaşımı | Hayır |
| Reklam | Yok |
| Uygulama içi satın alma | Yok |

**Beklenen sonuç: 4+.**

## Her iki mağazada da kaçınılacak kelime

Mağaza metninde **"bahis", "şans", "kasa aç", "çark"** gibi kelimeleri
kullanma. Metin tarayıcıları bunları kumar sinyali sayıp dereceyi
yükseltiyor ve bazı ülkelerde dağıtımı kısıtlıyor.
